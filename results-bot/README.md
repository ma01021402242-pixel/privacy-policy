# بوت وموقع نتيجة الثانوية العامة 🎓

تبعت رقم الجلوس → تجيلك النتيجة كاملة بالدرجات.

المشروع بياخد **ملف النتيجة** (إكسيل أو CSV أو JSON)، يحوّله لقاعدة بيانات SQLite،
وبعدين يقدّملك واجهتين للبحث فيه:

| | الملف | الوصف |
|---|---|---|
| 🤖 بوت تليجرام | `bot.py` | الطالب يبعت رقم الجلوس في الشات ويستلم النتيجة |
| 🌐 موقع | `web.py` | صفحة بحث عربية بسيطة + API |
| 📥 الاستيراد | `import_results.py` | يقرا ملف النتيجة ويحطه في القاعدة |

---

## 1. التثبيت

```bash
cd results-bot
python3 -m venv venv
source venv/bin/activate        # على ويندوز:  venv\Scripts\activate
pip install -r requirements.txt
```

## 2. جهّز الإعدادات

```bash
cp .env.example .env
```

وافتح `.env` وحط توكن البوت اللي هتاخده من [@BotFather](https://t.me/BotFather):

```
TELEGRAM_BOT_TOKEN=1234567890:AAH...
```

## 3. استورد ملف النتيجة

```bash
python import_results.py results.xlsx --replace
```

الأمر ده هيطبعلك الأعمدة اللي اتعرف عليها قبل ما يخزّن حاجة:

```
🧭 الأعمدة اللي اتعرفت عليها:
  - رقم الجلوس         : عمود «رقم الجلوس»
  - الاسم              : عمود «اسم الطالب»
  - المجموع            : عمود «المجموع»
  ...
✅ اتخزّن 700,000 طالب في results.db
```

**قبل ما تستورد فعليًا، جرّب `--dry-run` عشان تتأكد إن الأعمدة اتقريت صح:**

```bash
python import_results.py results.xlsx --dry-run
```

### الصيغ المدعومة

`.xlsx` `.xlsm` `.xls` `.csv` `.tsv` `.txt` `.json` `.jsonl` `.db/.sqlite`

الترميزات: UTF-8 و Windows-1256 (العربي القديم) بيتعرف عليهم أوتوماتيك.

### الخيارات

| الخيار | الوظيفة |
|---|---|
| `--db results.db` | مكان قاعدة البيانات |
| `--sheet "الشيت"` | اسم الشيت في ملف إكسيل فيه أكتر من واحد |
| `--table students` | اسم الجدول لو المصدر قاعدة SQLite |
| `--header-row 3` | رقم صف العناوين لو الاكتشاف التلقائي غلط |
| `--replace` | يمسح البيانات القديمة الأول |
| `--dry-run` | يعرض بس من غير ما يكتب |

### إزاي بيتعرف على الأعمدة؟

مش لازم الملف يبقى بشكل معيّن. السكريبت بيقرا عناوين الأعمدة وبيطابقها مع أسماء
معروفة (رقم الجلوس / الاسم / المجموع / النسبة / الحالة / المدرسة / الإدارة /
المحافظة / الشعبة)، وبيتعامل مع الهمزات والتاء المربوطة والتشكيل والأرقام الهندية.

**أي عمود تاني (المواد وغيرها) بيتخزّن زي ما هو وبيظهر في قسم «الدرجات»** — يعني
مش محتاج تعدّل أي كود لو الملف فيه مواد مختلفة.

لو الملف بيبدأ بصفوف ترويسة (اسم الوزارة مثلًا)، السكريبت بيلاقي صف العناوين لوحده،
ولو غلط استخدم `--header-row`.

## 4. شغّل البوت

```bash
python bot.py
```

الأوامر جوّه البوت:

| الأمر | الوظيفة |
|---|---|
| (رقم الجلوس) | النتيجة كاملة |
| (اسم الطالب) | بحث بالاسم — كلمتين على الأقل |
| `/top` | الأوائل حسب المجموع |
| `/stats` | حالة قاعدة البيانات (للأدمن) |
| `/id` | رقم حسابك — حطه في `ADMIN_IDS` |
| `/help` | المساعدة |

## 5. شغّل الموقع (اختياري)

```bash
python web.py                       # للتجربة على http://localhost:8000
```

للإنتاج استخدم سيرفر حقيقي:

```bash
pip install waitress
waitress-serve --host=0.0.0.0 --port=8000 web:app
```

الـ API:

- `GET /api/result?q=123456` → النتيجة أو قائمة مطابقات بالاسم
- `GET /api/config` → عنوان الصفحة وتاريخ آخر تحديث

## الاستضافة

البوت محتاج يفضل شغال ٢٤ ساعة. الاختيارات:

**سيرفر VPS (الأنسب لو الضغط عالي)** — عن طريق `systemd`:

```ini
# /etc/systemd/system/results-bot.service
[Unit]
Description=Results Telegram Bot
After=network.target

[Service]
WorkingDirectory=/opt/results-bot
ExecStart=/opt/results-bot/venv/bin/python bot.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now results-bot
sudo journalctl -u results-bot -f      # لمتابعة اللوج
```

**Railway / Render / Fly.io** — ارفع الريبو، حط `TELEGRAM_BOT_TOKEN` في الـ
Environment Variables، وخلي أمر التشغيل `python bot.py`.
مهم: ارفع ملف `results.db` معاه أو استورد الملف بعد الديبلوي، لأن التخزين عندهم
بيتمسح مع كل ديبلوي جديد.

**جهازك الشخصي** — يشتغل تمام للتجربة، بس البوت بيقف لما تقفل الجهاز.

## الإعدادات (`.env`)

| المتغيّر | الافتراضي | الوظيفة |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | — | توكن البوت (مطلوب) |
| `DB_PATH` | `results.db` | مكان قاعدة البيانات |
| `ADMIN_IDS` | فاضي | أرقام الأدمن مفصولة بفاصلة |
| `TOTAL_MAX` | `320` | المجموع الكلي — لحساب النسبة لو مش في الملف |
| `ENABLE_NAME_SEARCH` | `true` | تفعيل/تعطيل البحث بالاسم |
| `NAME_SEARCH_LIMIT` | `8` | أقصى عدد نتائج للبحث بالاسم |
| `RATE_LIMIT_REQUESTS` | `20` | أقصى عدد طلبات للمستخدم |
| `RATE_LIMIT_WINDOW` | `60` | مدة النافذة بالثواني |
| `WEB_PORT` | `8000` | بورت الموقع |

## الأداء

مقاسة على ملف تجريبي فيه **٧٠٠ ألف طالب**:

| العملية | الوقت |
|---|---|
| استيراد الملف كله | ~٢٤ ثانية |
| بحث برقم الجلوس | ~٠.٢ مللي ثانية |
| بحث بالاسم (من أول الاسم) | ~١٦ مللي ثانية |
| الأوائل `/top` | ~١ مللي ثانية |
| حجم قاعدة البيانات | ~٢٨٤ ميجا |

## أسئلة شائعة

**الملف عندي PDF — أعمل إيه؟**
حوّله لإكسيل الأول (Adobe Acrobat أو `tabula` أو أي أداة PDF-to-Excel)، وبعدين
استورده عادي. الاستيراد المباشر من PDF مش مدعوم لأن استخراج الجداول منه بيطلع
مظبوط بنسب متفاوتة والغلط فيه بيبان في درجات الطلبة.

**عايز أحدّث النتيجة بملف جديد؟**
`python import_results.py new.xlsx --replace` — البوت هيلقط التحديث فورًا من غير
ما تعيد تشغيله.

**البوت مش بيرد؟**
اتأكد إن التوكن صح، وإن `results.db` موجود، وشوف اللوج.

**عايز أزوّد عمود جديد (رأي المصحح مثلًا)؟**
مش محتاج تعمل حاجة — أي عمود مش متعرّف عليه بيظهر تلقائيًا في قسم «الدرجات».

## 🔒 الخصوصية والمسؤولية

- **متعملش commit لملف النتيجة ولا لقاعدة البيانات.** ملف `.gitignore` بيمنع ده
  تلقائيًا، بس خد بالك لو غيّرت المسارات.
- البيانات دي بيانات شخصية لقاصرين في أغلبها. حتى لو النتيجة منشورة رسميًا،
  خلّي وصولك ليها في حدود اللي محتاجه، ومتعملش تجميع أو تصدير جماعي ليها.
- **البحث بالاسم** بيسمح بالوصول لبيانات الطلبة من غير معرفة رقم الجلوس. لو ده
  مقلقك، اقفله: `ENABLE_NAME_SEARCH=false`.
- راجع شروط الجهة اللي نشرت النتيجة قبل ما تعيد نشرها في خدمة عامة.
- المشروع ده غير رسمي ومش تابع لوزارة التربية والتعليم — النتيجة الرسمية هي
  المعتمدة دايمًا.
