# دليل التشغيل خطوة بخطوة 🚀

الدليل ده موجّه لحد **مش مبرمج**. مش هتحتاج تكتب أوامر — كله بالدبل كليك.

الوقت المتوقع: من ١٥ لـ ٢٠ دقيقة أول مرة.

---

## الخطوة ١: اعمل البوت على تليجرام (٣ دقايق)

1. افتح تليجرام ودوّر على **[@BotFather](https://t.me/BotFather)** (اللي عليه علامة ✅ زرقا).
2. اضغط **Start**.
3. ابعتله: `/newbot`
4. هيسألك **اسم البوت** (ده اللي الناس هتشوفه). اكتب مثلًا:
   ```
   نتيجة الثانوية العامة
   ```
5. هيسألك **اليوزر نيم**، ولازم ينتهي بـ `bot` ويكون متاح. جرّب:
   ```
   thanawya_result_2026_bot
   ```
   لو مأخوذ هيقولك، غيّره وجرّب تاني.
6. هيبعتلك رسالة فيها سطر شكله كده:
   ```
   7123456789:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw
   ```
   **ده التوكن — انسخه واحفظه.** أي حد معاه التوكن يقدر يتحكّم في البوت.

> 💡 نسيت التوكن؟ ابعت `/mybots` لـ BotFather → اختار بوتك → API Token.

---

## الخطوة ٢: نزّل بايثون (٥ دقايق)

**ويندوز:**
1. روح [python.org/downloads](https://www.python.org/downloads/) واضغط الزرار الأصفر.
2. شغّل الملف، و**أهم حاجة**: علّم على ✅ **Add Python to PATH** في أول شاشة قبل ما تضغط Install.
3. لو نسيت تعلّم عليها، شيل بايثون ونزّله تاني — الخطوات اللي بعدها مش هتشتغل من غيرها.

**ماك أو لينكس:** بايثون غالبًا متسطّب خلاص، كمّل عادي.

## الخطوة ٣: نزّل الكود (دقيقتين)

1. افتح اللينك ده، هينزّل ملف مضغوط:
   ```
   https://github.com/ma01021402242-pixel/privacy-policy/archive/refs/heads/claude/secondary-results-bot-jfparx.zip
   ```
2. **فك الضغط** (كليك يمين → Extract All). مهم تفك الضغط فعلًا، متشتغلش من جوّه الملف المضغوط.
3. ادخل جوّه وهتلاقي فولدر اسمه **`results-bot`** — ده بيتنا.

## الخطوة ٤: التجهيز (٣ دقايق) — دبل كليك بس

جوّه فولدر `results-bot`:

**ويندوز:** اعمل **دبل كليك على `setup.bat`**

**ماك/لينكس:** افتح Terminal في الفولدر ونفّذ `./setup.sh`

هيفتحلك نافذة سودا وتشتغل لوحدها:

```
==============================================
   تجهيز بوت نتيجة الثانوية العامة
==============================================

⏳ [1/3] بنجهّز بيئة بايثون...
✅ اتعملت.

⏳ [2/3] بننزّل المكتبات... (ممكن تاخد دقيقة أو اتنين)
✅ اتنزّلت.

🔑 [3/3] التوكن
   الصق التوكن هنا واضغط Enter:
```

**الصق التوكن** (كليك يمين في النافذة السودا = لصق) واضغط Enter.

```
✅ التوكن اتحفظ في .env
🎉 التجهيز خلص!
```

كده خلصنا التجهيز. لو ظهرت رسالة حمرا، شوف [قسم المشاكل](#المشاكل-الشائعة-وحلولها) تحت.

> 🔒 السكريبت بيتأكد إن شكل التوكن سليم قبل ما يحفظه، وبيقولك لو فيه حاجة ناقصة.

## الخطوة ٥: ارفع ملف النتيجة (٣ دقايق) ⭐

**ويندوز:** **اسحب ملف النتيجة (الإكسيل) وارميه فوق ملف `import.bat`** — سحب وإفلات عادي.

**ماك/لينكس:** `./import.sh results.xlsx`

هيقرا الملف ويعرضلك كشف بالأعمدة اللي فهمها **قبل ما يخزّن أي حاجة**:

```
🧭 الأعمدة اللي اتعرفت عليها:
  - رقم الجلوس         : عمود «رقم الجلوس»
  - الاسم              : عمود «اسم الطالب»
  - المجموع            : عمود «المجموع»
  - الحالة             : عمود «الرأي»
  - أعمدة إضافية (9) : اللغة العربية، الرياضيات، الفيزياء، ...

👀 عيّنة من البيانات:
   رقم الجلوس: 100001 | الاسم: محمد أحمد | المجموع: 302.0

✅ نستورد؟ اكتب y واضغط Enter:
```

**راجع الكشف قبل ما تكتب y:**

| اللي شايفه | يعني إيه |
|---|---|
| رقم الجلوس والاسم والمجموع طالعين صح | تمام ✅ اكتب `y` |
| المواد ظاهرة تحت «أعمدة إضافية» | ده الطبيعي — هتظهر في الدرجات ✅ |
| مكتوب «(غير موجود)» جنب حاجة | عادي لو الملف أصلًا مفيهوش العمود ده |
| **رقم الجلوس «غير موجود»** | ❌ اكتب `n` وشوف [المشاكل](#المشاكل-الشائعة-وحلولها) |
| العيّنة طالعة مبعترة أو غلط | ❌ اكتب `n` وشوف [المشاكل](#المشاكل-الشائعة-وحلولها) |

بعد `y`:
```
✅ اتخزّن 700,000 طالب في results.db
```

> 🔄 **جالك ملف محدّث بعدين؟** اسحبه وارميه على `import.bat` تاني. البوت هيلقط التحديث فورًا من غير ما توقّفه.

## الخطوة ٦: شغّل البوت (دقيقة)

**ويندوز:** دبل كليك على **`run-bot.bat`**
**ماك/لينكس:** `./run-bot.sh`

```
البوت اشتغل ✅  افتحه من هنا: https://t.me/thanawya_result_2026_bot
لإيقافه: اضغط Ctrl+C
```

**سيب النافذة دي مفتوحة** — البوت شغال طول ما هي فاتحة.

افتح اللينك اللي ظهرلك، اضغط Start، وابعت رقم جلوس. المفروض تجيلك النتيجة كاملة 🎉

## الخطوة ٧: لمسات أخيرة على البوت (اختياري)

ارجع لـ BotFather وابعتله:

- `/setdescription` → وصف يظهر للطالب قبل ما يضغط Start
- `/setuserpic` → صورة للبوت
- `/setcommands` → القايمة اللي بتظهر لما يكتب `/`. الصق ده:
  ```
  start - البداية
  help - المساعدة
  top - الأوائل حسب المجموع
  ```

## الخطوة ٨: خلّيه شغال ٢٤ ساعة

البوت بيقف لما تقفل الجهاز أو النافذة. الحلول:

| الحل | التكلفة | مناسب لـ |
|---|---|---|
| **جهازك** | مجاني | التجربة، أو عدد قليل من الناس |
| **VPS** (Hetzner / Contabo / DigitalOcean) | ~٥$ شهريًا | ✅ الأنسب لو النتيجة هتتنشر لناس كتير |
| **Railway / Render** | باقة مجانية محدودة | تجربة موسّعة |

### لو اخترت VPS (سيرفر لينكس)

بعد ما تشتري السيرفر وتدخل عليه بـ SSH:

```bash
sudo apt update && sudo apt install -y python3-venv git
git clone -b claude/secondary-results-bot-jfparx \
  https://github.com/ma01021402242-pixel/privacy-policy.git
cd privacy-policy/results-bot
./setup.sh                                  # هيسألك عن التوكن
```

ارفع ملف النتيجة للسيرفر (نفّذ ده من جهازك مش من السيرفر):
```bash
scp results.xlsx root@عنوان_السيرفر:~/privacy-policy/results-bot/
```

وارجع للسيرفر:
```bash
./import.sh results.xlsx
```

وخلّيه يشتغل تلقائيًا ويرجع لوحده لو وقع:

```bash
sudo tee /etc/systemd/system/results-bot.service > /dev/null <<'EOF'
[Unit]
Description=Results Telegram Bot
After=network.target

[Service]
WorkingDirectory=/root/privacy-policy/results-bot
ExecStart=/root/privacy-policy/results-bot/venv/bin/python bot.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl enable --now results-bot
sudo systemctl status results-bot        # للتأكد إنه شغال
sudo journalctl -u results-bot -f        # لمتابعة اللوج
```

كده البوت شغال ٢٤ ساعة وبيقوم لوحده لو السيرفر اترستارت.

## المشاكل الشائعة وحلولها

### التجهيز (`setup.bat`)

**`[ERROR] Python was not found`**
بايثون مش متسطّب، أو اتسطّب من غير ما تعلّم على **Add Python to PATH**.
الحل: نزّله تاني من [python.org](https://www.python.org/downloads/) وعلّم على الخيار ده في أول شاشة.

**النافذة السودا بتفتح وتقفل بسرعة**
معناها إن `setup.bat` مش لاقي الملفات اللي جنبه — غالبًا انت شغّلته من **جوّه الملف المضغوط**.
الحل: فك الضغط الأول (كليك يمين → Extract All)، وبعدين شغّله من الفولدر المفكوك.

**قال «الشكل ده مش مطابق لتوكن تليجرام»**
غالبًا نسخت جزء من السطر. التوكن كامل شكله: أرقام + نقطتين + حروف وأرقام طويلة.
ارجع لرسالة BotFather وانسخ السطر كله.

**اللصق مش شغال في النافذة السودا**
`Ctrl+V` أحيانًا مش بيشتغل في cmd القديم — استخدم **كليك يمين** بدالها، أو **Ctrl+Shift+V**.

### الاستيراد (`import.bat`)

**❌ «مقدرتش ألاقي عمود رقم الجلوس»**
غالبًا صف العناوين مش أول صف في الملف. افتح الإكسيل وشوف العناوين في أنهي صف (مثلًا التالت)، وبعدين افتح النافذة السودا في الفولدر ونفّذ:
```bat
venv\Scripts\python.exe import_results.py results.xlsx --header-row 3 --confirm
```

**الملف فيه أكتر من شيت**
```bat
venv\Scripts\python.exe import_results.py results.xlsx --sheet "اسم الشيت" --confirm
```

**العيّنة طالعة مبعترة**
جرّب `--header-row` بأرقام مختلفة لحد ما العيّنة تطلع مظبوطة.

**الملف عندي PDF**
حوّله لإكسيل الأول (Adobe Acrobat أو أي موقع PDF to Excel)، وبعدين اسحبه على `import.bat` عادي.

**اسم الملف عربي وبيعمل مشاكل**
غيّر اسمه لاسم إنجليزي بسيط زي `results.xlsx`.

### التشغيل (`run-bot.bat`)

**❌ «تليجرام رفض التوكن»**
افتح ملف `.env` بالـ Notepad وقارن التوكن باللي بعتهولك BotFather. لازم يكون:
```
TELEGRAM_BOT_TOKEN=7123456789:AAH...
```
من غير مسافات ولا علامات تنصيص. أسهل حل: شغّل `setup.bat` تاني واختار تغيير التوكن.

**❌ «مقدرتش أوصل لتليجرام»**
النت مش شغال، أو تليجرام محجوب عندك. جرّب VPN، أو شغّل البوت على سيرفر.

**البوت رد «النتيجة لسه مترفعتش»**
معناها إن ملف النتيجة مااتستوردش. ارجع للخطوة ٥.

**بيقول «مفيش نتيجة لرقم الجلوس»**
جرّب رقم جلوس انت متأكد إنه موجود في الملف. لو برضه مش لاقيه، يبقى عمود رقم الجلوس اتقرا غلط — ارجع للخطوة ٥ وراجع الكشف.

## تنبيهات مهمة 🔒

- **متعملش رفع (commit) لملف النتيجة ولا لـ `results.db` ولا `.env` على GitHub.** المشروع فيه حماية تلقائية بتمنع ده، بس خد بالك.
- التوكن زي كلمة السر — لو اتسرّب، روح لـ BotFather واعمل `/revoke`.
- البيانات دي بيانات شخصية لطلبة أغلبهم قاصرين. حتى لو النتيجة منشورة رسميًا، خلّي استخدامك في حدود اللي محتاجه.
- **البحث بالاسم** بيخلي أي حد يوصل لنتيجة أي طالب من غير ما يعرف رقم جلوسه. لو مش عايز ده، افتح `.env` وحط:
  ```
  ENABLE_NAME_SEARCH=false
  ```
- المشروع غير رسمي ومش تابع للوزارة — النتيجة الرسمية هي المعتمدة دايمًا.
