# دليل التشغيل خطوة بخطوة 🚀

الدليل ده موجّه لحد **مش مبرمج**. اتبع الخطوات بالترتيب وهتلاقي البوت شغال.

الوقت المتوقع: من ٢٠ لـ ٣٠ دقيقة أول مرة.

---

## الخطوة ١: اعمل البوت على تليجرام (٣ دقايق)

1. افتح تليجرام ودوّر على **[@BotFather](https://t.me/BotFather)** (اللي عليه علامة ✅ زرقا).
2. اضغط **Start**.
3. ابعتله: `/newbot`
4. هيسألك **اسم البوت** (ده اللي الناس هتشوفه). اكتب مثلًا:
   ```
   نتيجة الثانوية العامة
   ```
5. هيسألك **اليوزر نيم**، ولازم ينتهي بـ `bot` ويكون متاح. جرّب:
   ```
   thanawya_result_2026_bot
   ```
   لو مأخوذ هيقولك، غيّره وجرّب تاني.
6. هيبعتلك رسالة فيها سطر شكله كده:
   ```
   7123456789:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw
   ```
   **ده التوكن — احفظه ومتديهوش لحد.** أي حد معاه التوكن يقدر يتحكّم في البوت.

> 💡 نسيت التوكن؟ ابعت `/mybots` لـ BotFather → اختار بوتك → API Token.

**اختياري بس مفيد** — من BotFather بردو:
- `/setdescription` → وصف يظهر قبل ما الطالب يضغط Start
- `/setuserpic` → صورة للبوت
- `/setcommands` → القايمة اللي بتظهر لما يكتب `/`. الصق ده:
  ```
  start - البداية
  help - المساعدة
  top - الأوائل حسب المجموع
  ```

## الخطوة ٢: نزّل بايثون على جهازك (٥ دقايق)

**ويندوز:**
1. روح [python.org/downloads](https://www.python.org/downloads/) واضغط الزرار الأصفر.
2. شغّل الملف، و**مهم جدًا**: علّم على ✅ **Add Python to PATH** في أول شاشة، وبعدين Install Now.
3. للتأكد: افتح **Command Prompt** (اكتب `cmd` في قايمة ابدأ) واكتب:
   ```
   python --version
   ```
   لازم يطلعلك رقم زي `Python 3.12.x`. لو طلعت رسالة خطأ، يبقى نسيت تعلّم على Add to PATH — نزّله تاني.

**ماك أو لينكس:** بايثون غالبًا متسطّب. اتأكد بـ `python3 --version`.

## الخطوة ٤: ثبّت المكتبات (٣ دقايق)

افتح **Command Prompt** وروح لمكان الفولدر. أسهل طريقة:
افتح فولدر `results-bot`، اضغط في شريط العنوان فوق، اكتب `cmd` واضغط Enter.

بعدين نفّذ الأوامر دي واحد ورا التاني:

```bat
python -m venv venv
venv\Scripts\activate

```

**على ماك/لينكس:**
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

لو شفت `(venv)` في أول السطر يبقى تمام ✅
(كل مرة تفتح نافذة جديدة لازم تعيد أمر `activate`.)

## الخطوة ٦: ارفع ملف النتيجة (٥ دقايق) ⭐

دي أهم خطوة.

### ٦.١ — حط الملف في مكانه

انسخ ملف النتيجة (إكسيل أو CSV) جوّه فولدر `results-bot`، و**غيّر اسمه لاسم إنجليزي بسيط** زي `results.xlsx` عشان تتجنب مشاكل الأسماء العربية في سطر الأوامر.

### ٦.٢ — اعمل فحص أول (من غير ما يتخزّن حاجة)

```bat
python import_results.py results.xlsx --dry-run
```

هيطلعلك كشف بالأعمدة اللي فهمها:

```
🧭 الأعمدة اللي اتعرفت عليها:
  - رقم الجلوس         : عمود «رقم الجلوس»
  - الاسم              : عمود «اسم الطالب»
  - المجموع            : عمود «المجموع»
  - الحالة             : عمود «الرأي»
  - أعمدة إضافية (9) : اللغة العربية، الرياضيات، الفيزياء، ...

👀 عيّنة من البيانات:
   رقم الجلوس: 100001 | الاسم: محمد أحمد | المجموع: 302.0
```

**راجع الكشف ده كويس:**

| اللي شايفه | يعني إيه |
|---|---|
| رقم الجلوس والاسم والمجموع صح | تمام، كمّل ✅ |
| المواد ظاهرة في «أعمدة إضافية» | ده الطبيعي — هتظهر في الدرجات ✅ |
| مكتوب «(غير موجود)» جنب حاجة | عادي لو الملف أصلًا مفيهوش العمود ده |
| **رقم الجلوس «غير موجود»** | ❌ وقف — شوف قسم المشاكل تحت |
| البيانات في العيّنة مقلوبة أو غلط | ❌ وقف — شوف قسم المشاكل تحت |

### ٦.٣ — استورد فعليًا

```bat
python import_results.py results.xlsx --replace
```

```
✅ اتخزّن 700,000 طالب في results.db
```

خلاص، الداتا بقت جوّه البوت. `--replace` معناها امسح القديم وحط الجديد.

> 🔄 **جالك ملف محدّث بعدين؟** نفّس الأمر ده تاني بس. البوت هيلقط التحديث فورًا من غير ما توقّفه.

## الخطوة ٨: خلّيه شغال ٢٤ ساعة

المشكلة: البوت بيقف لما تقفل الجهاز أو النافذة. الحلول:

| الحل | التكلفة | مناسب لـ |
|---|---|---|
| **جهازك** | مجاني | التجربة، أو عدد قليل من الناس |
| **VPS** (Hetzner / Contabo / DigitalOcean) | ~٥$ شهريًا | ✅ الأنسب لو النتيجة هتتنشر لناس كتير |
| **Railway / Render** | باقة مجانية محدودة | تجربة موسّعة |

### لو اخترت VPS (سيرفر لينكس)

بعد ما تشتري السيرفر وتدخل عليه بـ SSH:

```bash
sudo apt update && sudo apt install -y python3-venv git
git clone -b claude/secondary-results-bot-jfparx \
  https://github.com/ma01021402242-pixel/privacy-policy.git
cd privacy-policy/results-bot
python3 -m venv venv && ./venv/bin/pip install -r requirements.txt
cp .env.example .env && nano .env          # حط التوكن
```

ارفع ملف النتيجة للسيرفر (من جهازك):
```bash
scp results.xlsx root@عنوان_السيرفر:~/privacy-policy/results-bot/
```

وبعدين على السيرفر:
```bash
./venv/bin/python import_results.py results.xlsx --replace
```

خلّيه يشتغل تلقائيًا ويرجع لوحده لو وقع:

```bash
sudo tee /etc/systemd/system/results-bot.service > /dev/null <<'EOF'
[Unit]
Description=Results Telegram Bot
After=network.target

[Service]
WorkingDirectory=/root/privacy-policy/results-bot
ExecStart=/root/privacy-policy/results-bot/venv/bin/python bot.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
EOF

sudo systemctl enable --now results-bot
sudo systemctl status results-bot        # للتأكد إنه شغال
sudo journalctl -u results-bot -f        # لمتابعة اللوج
```

كده البوت شغال ٢٤ ساعة وبيقوم لوحده لو السيرفر اترستارت.

## المشاكل الشائعة وحلولها

**`python` مش متعرّف عليه**
نسيت تعلّم على **Add Python to PATH** وقت التثبيت. نزّل بايثون تاني وعلّم عليها.

**`pip` بيقول Permission denied**
اتأكد إنك عامل `venv\Scripts\activate` وشايف `(venv)` في أول السطر.

**❌ «مقدرتش ألاقي عمود رقم الجلوس»**
غالبًا صف العناوين مش أول صف في الملف. افتح الإكسيل وشوف العناوين في أنهي صف (مثلًا الصف التالت)، وبعدين:
```bat
python import_results.py results.xlsx --header-row 3 --dry-run
```
ولو الملف فيه أكتر من شيت:
```bat
python import_results.py results.xlsx --sheet "اسم الشيت" --dry-run
```

**البيانات في العيّنة طالعة غلط أو مبعترة**
جرّب `--header-row` بأرقام مختلفة مع `--dry-run` لحد ما العيّنة تطلع مظبوطة.

**الملف عندي PDF**
حوّله لإكسيل الأول (Adobe Acrobat أو موقع تحويل PDF to Excel)، وبعدين استورده عادي.

**البوت شغال بس مش بيرد**
- اتأكد إن التوكن في `.env` صح ومن غير مسافات
- اتأكد إن `results.db` اتعمل (لازم تكون عملت الخطوة ٦)
- بصّ على النافذة اللي فيها البوت، الخطأ بيتكتب فيها

**بيقول «مفيش نتيجة لرقم الجلوس»**
جرّب رقم جلوس تعرف إنه موجود في الملف. لو برضه مش لاقيه، يبقى عمود رقم الجلوس اتقرا غلط — ارجع لـ `--dry-run` وراجع.

## تنبيهات مهمة 🔒

- **متعملش رفع (commit) لملف النتيجة ولا لـ `results.db` ولا `.env` على GitHub.** المشروع فيه حماية تلقائية بتمنع ده، بس خد بالك.
- التوكن زي كلمة السر — لو اتسرّب، روح لـ BotFather واعمل `/revoke`.
- البيانات دي بيانات شخصية لطلبة أغلبهم قاصرين. حتى لو النتيجة منشورة رسميًا، خلّي استخدامك في حدود اللي محتاجه.
- **البحث بالاسم** بيخلي أي حد يوصل لنتيجة أي طالب من غير ما يعرف رقم جلوسه. لو مش عايز ده، افتح `.env` وحط:
  ```
  ENABLE_NAME_SEARCH=false
  ```
- المشروع غير رسمي ومش تابع للوزارة — النتيجة الرسمية هي المعتمدة دايمًا.
